# 测试用例文档模板

## 用例结构

每个用例必须包含以下字段：

```markdown
## 用例 <编号>: <简明描述>
- **目标**: <验证的具体行为>
- **输入**: <具体输入值或前置状态>
- **预期输出**: <明确的预期结果>
- **通过标准**: <可自动或手动验证的判断条件>
- **优先级**: P0(阻塞) / P1(重要) / P2(一般)
```

## 完整示例

```markdown
# 测试用例：修复搜索分页 bug

## 用例 TC-01: 正常分页（第1页，每页10条）
- **目标**: 验证正常分页返回正确数据
- **输入**: page=1, pageSize=10, 总数据 25 条
- **预期输出**: 返回前 10 条，hasNext=true
- **通过标准**: 返回数组长度为 10，hasNext 字段为 true
- **优先级**: P0

## 用例 TC-02: 边界——最后一页
- **目标**: 验证最后一页返回剩余数据
- **输入**: page=3, pageSize=10, 总数据 25 条
- **预期输出**: 返回后 5 条，hasNext=false
- **通过标准**: 返回数组长度为 5，hasNext 字段为 false
- **优先级**: P0

## 用例 TC-03: 边界——空结果
- **目标**: 验证无数据时的分页行为
- **输入**: page=1, pageSize=10, 总数据 0 条
- **预期输出**: 空数组，hasNext=false
- **通过标准**: 返回空数组，hasNext 为 false，无异常
- **优先级**: P0

## 用例 TC-04: 异常——页码为 0
- **目标**: 验证非法页码的异常处理
- **输入**: page=0, pageSize=10
- **预期输出**: 返回错误码 INVALID_PARAM
- **通过标准**: 返回 400 错误，错误码为 INVALID_PARAM
- **优先级**: P1
```

## 用例编号规范

- 格式：`TC-NN`（两位数字，补零）
- 顺序：按测试优先级排列，P0 在前
- 分类：大型需求可增加前缀，如 `TC-AUTH-01`（认证模块）、`TC-ORD-01`（订单模块）

## 优先级定义

| 优先级 | 定义 | 阻塞发布？ |
|--------|------|-----------|
| P0 | 核心功能、主流程、安全相关 | 是 |
| P1 | 重要边界、异常处理、回归场景 | 否（但应修复） |
| P2 | 边缘场景、兼容性、性能基准 | 否 |
