# Experience：项目经验库

本目录沉淀本项目**反直觉、不可直接发现、可复用**的工程经验（隐性约束、隐式机制、非常规坑），
与 `project_wiki/` 的代码地图互补：wiki 回答"现在是什么"，经验库回答"为什么会这样 / 别踩这个坑"。

## 加载约定

- **按需加载，不进默认启动预加载集合**：命中模块后先查本页索引，再加载映射到的经验文件；
  文件名不要求与类名或模块名直接相同，未命中索引时不加载。
- 新经验的提炼、去重、垃圾过滤委托 `team-experience-curator` skill 执行，本目录不复制其规则。

## 条目规范

- 字段：`title / when / what / why / scope / component / source`（事实无法验证时加 `存疑`）。
- 每条在自身 `###` 区块内附带 `<!-- audit: ... -->` 审计注释：镜头判定、垃圾过滤结果、
  证据轮次、事实校验结论。
- 禁止收录：通用常识、会话摘要、一次性 case、用户主观偏好、当前规范等价内容。
