# 阶段：设计稿收料

## 目标

多源物料一站式收齐，禁止通用抓取替代。

## 物料通道

| 物料类型 | 专用通道 | 禁止 |
|---------|---------|------|
| PRD/任务单 | `docs/原始需求.md`、`docs/任务单.md` 或专用 MCP/脚本 | web_fetch |
| 设计稿 | Figma MCP / `scan_materials.py` | web_fetch |
| 接口协议 | `docs/接口协议.md` 或协议仓库脚本 | web_fetch |
| 会议纪要/上下文 | 用户直接输入 | 通用搜索 |

## 收料输出

- 候选物料清单
- 每份物料的来源、类型、状态（完整/缺失/待确认）

## 红线

- **RL-05**：多源物料必须走专用通道，禁止通用 web_fetch 替代。
- **RL-17**：设计稿筛选必须脚本直方图 + 白名单，禁止 LLM 手工分桶。
