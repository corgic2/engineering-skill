# 工具箱死角清单

只列"不能做什么 + 替代方案"。按构建/框架、语言、调试定位分类。

## 构建/框架通用

| 死角 | 为什么不行 | 替代方案 |
|------|-----------|---------|
| 在源码目录直接构建 | 污染源码树 | 强制 out-of-source：构建目录独立 |
| 构建后不检查退出码 | stdout 可能被截断 | 检查退出码 + sentinel 文件 |
| 信任 AI 自报完成 | stdout 会截断/置后台 | 以 sentinel 文件/截图/日志为判据 |
| 硬编码配置/密钥/连接串 | 泄露风险、环境不可移植 | 配置文件/环境变量/密钥管理服务 |

## C++/Qt/CMake 示例

| 死角 | 为什么不行 | 替代方案 |
|------|-----------|---------|
| 不指定 generator 直接 `cmake .` | 可能选错 VS/MinGW/Ninja | 显式 `cmake -G "Ninja Multi-Config" -B build` |
| 跨线程直接操作 QWidget | 崩溃或未定义行为 | signal/slot + Qt::QueuedConnection |
| 硬编码字号/颜色 | 设计稿走样、Dark Mode 失效 | 查 `ui_mapping.md` 使用 styled API |
| `new` 后无对应 `delete` | 内存泄漏 | `std::unique_ptr`/`QScopedPointer` |

## Python 示例

| 死角 | 为什么不行 | 替代方案 |
|------|-----------|---------|
| 用 `print` 排查线上问题 | 无级别、无持久化 | 统一 `logging` 模块 |
| 在模块级执行耗时初始化 | 导入慢、测试困难 | 延迟初始化/工厂函数 |
| 可变默认参数 | 共享状态导致意外修改 | 默认 `None`，函数内新建 |

## JavaScript/TypeScript 示例

| 死角 | 为什么不行 | 替代方案 |
|------|-----------|---------|
| 直接操作全局状态 | 测试困难、并发问题 | 状态管理库/依赖注入 |
| 忽略 Promise rejection | 静默失败 | `await` + `try/catch` 或 `.catch()` |
| `==` 比较 | 类型隐式转换陷阱 | `===` |

## 调试/定位通用

| 死角 | 为什么不行 | 替代方案 |
|------|-----------|---------|
| 直接 grep 中文业务词 | 代码里是英文命名 | 先用 5 维矩阵扩展搜索词 |
| 只看函数名不看调用链 | 改错位置 | 用 `rg` 找调用方，画图确认 |
| 修改前不读完整方法 | 发明独此一家模式 | 先看后写，模仿已有 |
